# Text-readability-analyser-TSA
📖 Text Readability Analyzer using Python

📌 Project Overview

This project analyzes an English text and estimates how easy or difficult it is to read.

It uses readability formulas such as Flesch Reading Ease and Flesch-Kincaid Grade Level.

🎯 Objective

To determine the readability and approximate reading grade level of a given piece of English text.

🛠️ Technologies Used

- Python
- Google Colab
- Textstat
- Natural Language Processing (NLP)

⚙️ How It Works

1. The user enters an English paragraph.
2. The text is processed using the "textstat" library.
3. The Flesch Reading Ease score is calculated.
4. The Flesch-Kincaid Grade Level is calculated.
5. The program displays the reading difficulty.

🚀 How to Run

1. Open Google Colab.
2. Upload "Readability_Analyzer.ipynb".
3. Run the installation cell.
4. Run the analysis cell.
5. Enter an English paragraph.
6. View the readability results.
